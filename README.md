# AI-Risk-Audit

Purpose: answers customer questions about accounts, cards, fees and branch info.
Users: the public, includeing vulnerable customers (elderly, in financial difficulty, non-native English speakers).
In scope: general FAQs, explaining products, pointing people to the right team.
Out of scope: giving financial advice, approving loans, accessing real account data.
Model: the open model that will run plus the system prompt.
Human oversight: customers can ask for a human; complaints go to staff.
